# 仕様書

## 目的

naoiwが制作した公開Webアプリケーションの入口。記事投稿、ブログ、RSS、タグ別ページは扱わない。

## ページ構成

- URL: `/` の1ページ。ヘッダー、サイト概要、作品一覧、フッター。
- 作品カードは名称・説明・分類・公開先リンク・GitHubソースリンク・任意の状態ラベルを表示。
- カードの主領域はアプリ公開先、フッターの「GitHub」はソースへの別リンク。
- 分類は「すべて」「ダッシュボード」「ツール」「実験・その他」。選択した分類で件数とカードを更新する。
- URLは明示的に管理。GitHub上の全リポジトリを自動取得して公開するわけではない。

## レスポンシブ

- 941px以上: 3列
- 621〜940px: 2列
- 620px以下: 1列
- 固定最小幅を置かず、狭い画面での横スクロールを防ぐ。
- タップ対象は42px以上を目安とし、キーボードフォーカスとOSの動き低減設定に対応する。

## データ

`app/projects.json` の配列で作品を管理する。項目数をコードやテストに固定しない。

| キー | 必須 | 説明 |
| --- | --- | --- |
| `id` | 必須 | 重複しない英小文字・数字・ハイフンの識別子 |
| `name` | 必須 | カードの表示名 |
| `description` | 必須 | 一文の説明 |
| `category` | 必須 | `dashboard` / `tool` / `experiment` |
| `initials` | 必須 | サムネイル代わりの1〜3文字 |
| `url` | 必須 | HTTPSの公開アプリURL |
| `repository` | 必須 | 公開GitHubリポジトリのURL |
| `status` | 任意 | 「開発中」などの補足 |

追加・並べ替えはJSONの配列を編集する。存在しない公開先や機密データのURLは掲載しない。

## SEO・アクセシビリティ

- HTML言語は日本語。単一のh1、セクションごとのh2、各カードのh3。
- 独立したアプリURLへのリンクとリポジトリURLをスクリーンリーダーで区別する。
- OGP・description・canonical・robots・sitemapはトップページに合わせて設定する。
- フィルターの状態は`aria-pressed`、表示件数の変更は`aria-live`で通知する。
